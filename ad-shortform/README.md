# 각산 AI 업무 자동화 1:1 컨설팅 숏폼 광고 (32초)

- **완성 영상**: `out/gaksan_ai_ad.mp4` (1080×1920 세로, 30fps, 32초, 릴스·쇼츠·틱톡용)
- **대상**: 보험설계사, 소상공인, 1인 사장님, AI 초보
- **핵심 메시지**: 시간 절약·업무 자동화 + 누구나 쉽게 시작
- **행동 유도(CTA)**: 1:1 컨설팅 신청 (프로필 링크·DM)

## 레퍼런스 스타일
**키네틱 타이포그래피 + '문제 → 전환 → 해결 → CTA' 구성의 숏폼 광고 문법**
(국내 핀테크·SaaS 광고에서 많이 쓰는 큰 글자 중심 연출)

- 소리 없이 보는 사람이 많은 숏폼 특성상 **자막 자체가 화면의 주인공**
- 0~8초는 붉은 밤 톤(퇴근 후 야근의 압박), 8초에 **흰 플래시와 함께 민트 톤으로 전환**(AI 도입 이후)
- 체크리스트가 하나씩 **'AI 자동'으로 체크되는 장면**에서 자동화 효과를 직관적으로 보여 줌
- 과장 광고 위험을 줄이려고 **근거 없는 수치는 쓰지 않음**

## 음악
**오리지널 업비트 테크 팝 (120 BPM, 직접 합성해서 저작권 문제 없음)**: `make_music.py` → `assets/music.wav`
- 0~8초: 시계 초침 틱 + 심장박동 킥 + 낮은 단조 패드(Am)로 긴장감
- 7~8초: 라이저 → **8초 전환 장면에 맞춰 드롭**
- 8~31초: C–G–Am–F 진행의 밝은 장조 코드, 플럭 아르페지오, 킥·클랩·하이햇으로 희망적인 분위기
- 31초: 마지막 임팩트 후 페이드아웃 (CTA를 강조)

내레이션을 넣을 계획이라면, 음악 볼륨을 약 -12dB 낮춰 섞으면 됩니다.

## 수정 및 다시 만들기
```bash
python3 make_music.py assets/music.wav   # 음악 다시 생성
node render.js 30                         # 영상 다시 렌더링 → out/gaksan_ai_ad.mp4
```
- 문구는 `ad.html`의 각 장면(`#s1`~`#s6`)에서 바로 고칠 수 있습니다. 노출 시점은 `data-s`(초) 값입니다.
- `ad.html`을 브라우저에서 열면 실시간으로 미리 볼 수 있습니다.
