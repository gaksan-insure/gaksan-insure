# 간병인보험 세로 숏폼 광고 (2026-11)

- 형식: 9:16 세로 영상, 1080x1920, 30fps, 48초, 자막 + 음악 (내레이션 없음)
- 톤: 다큐 감성. 따뜻한 필름톤(Kodak Portra 느낌), 은은한 필름 그레인, 천천히 밀고 당기는 카메라
- 음악: 66BPM 솔로 피아노 (Am–F–C–G). 27초 '간병인 보험' 장면부터 F–C–G로 밝아지며 현악 패드가 들어오고, 마지막은 C장조로 해결

## 장면 구성

| # | 시간 | 장면 | 자막 |
|---|---|---|---|
| 1 | 0–5초 | 병실 창가에 앉은 아버지의 뒷모습 | 자식한테 / 짐 되기 싫으시지요? |
| 2 | 5–11초 | 침대 옆 탁자 위의 봉투·약통, 주름진 손 | 병원비는 보험이 냅니다. → 간병비는 자식이 냅니다. |
| 3 | 11–14초 | 밤 사무실에서 휴대폰을 보는 딸 | 딸은 회사에 / 휴가를 냅니다. |
| 4 | 14–18초 | 노을 지는 기차 창가의 아들 | 아들은 주말마다 / 내려옵니다. |
| 5 | 18–23초 | 병원 복도에 홀로 선 며느리 | 며느리는 / 말을 아낍니다. → 그리고 다들 / 괜찮다고 합니다. |
| 6 | 23–27초 | 이불을 꽉 쥔 손 클로즈업 | 그런데 정작, / 괜찮지 않으실 겁니다. |
| 7 | 27–34초 | 간병인이 아버지를 일으켜 드리는 장면 | 간병인 보험은 / 그 미안함을 대신 / 내주는 보험입니다. → 간병인을 쓴 날만큼 / 보험에서 나옵니다. |
| 8 | 34–40초 | 닫히는 문틈으로 새는 빛 | 다만 한 살 늘 때마다 → 보험료는 오르고, / 들어갈 문은 좁아집니다. |
| 끝 | 40–48초 | 크림색 엔드카드와 로고 | 지금 가진 보험부터 같이 보겠습니다. / '간병' 두 글자만 답장 주세요. / 각산보험대리점 대표 김대인 ☎ 010-8362-5177 |

영상은 여러 고객에게 공통으로 보내도록 '○○님'을 빼고 "그런데 정작, 괜찮지 않으실 겁니다."로 바꿨습니다. 이름은 문자 본문에만 넣습니다.

## 다시 만들기

`img/s1.png`부터 `img/s8.png`까지, `fonts/`(나눔명조 400·700·800, Noto Sans KR 500), `logo.png`를 준비한 뒤 실행합니다.

```
python3 music.py    # music.wav 생성
python3 render.py   # final.mp4 생성
```

## 발송 전 확인할 것

- 보험 광고는 보험협회 광고심의를 받아야 합니다. 심의필 번호를 받으면 엔드카드 하단 안내문 옆에 넣으세요.
- 엔드카드 하단에 "보험계약 체결 전 상품설명서 및 약관을 반드시 읽어보시기 바랍니다."를 넣었습니다. 심의 기준에 맞춰 문구를 조정하세요.
